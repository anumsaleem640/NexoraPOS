# NexoraPOS UI Guidelines

## Principles
Clean, responsive, accessible, consistent, fast, touch-friendly, and keyboard-friendly.

## Responsive Support
Support mobile, tablet, desktop, and large desktop. Components should adapt rather than merely shrink.

## Admin Layout
Desktop: sidebar + header + main content.
Mobile: header + main content + bottom navigation, with optional drawer navigation.

## Reusable Components
Button, Input, Select, Checkbox, Modal, Card, Table, Badge, Alert, Toast, Dropdown, Sidebar, Header, Pagination, Loading State, Empty State, Error State.

## Accessibility
Use semantic HTML, accessible labels, keyboard navigation, visible focus states, and sufficient contrast.

## Loading
Every asynchronous operation should provide an appropriate loading state.

## Errors
Errors should be understandable and actionable. Avoid exposing technical details to end users.

## Forms
Validate input, show field-level errors, preserve valid input, and prevent duplicate submissions.

## Tables
Support responsive behavior using horizontal scrolling, card transformations, or prioritized columns.

## Design Tokens
Centralize typography, spacing, radius, shadows, breakpoints, z-index, and motion. Avoid arbitrary values when tokens exist.
