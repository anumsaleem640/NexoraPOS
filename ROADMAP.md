# NexoraPOS Roadmap

## Version 1.0 — Foundation
Infrastructure: monorepo, backend API, encrypted file persistence, authentication, authorization.
Business: users, products, categories, inventory, orders, customers, settings.
Clients: Admin Dashboard, Customer Storefront, Mobile Application.

## Version 1.1 — Operational Improvements
Potential features:
- Advanced inventory reports
- Sales reports
- Dashboard analytics
- Improved search
- Bulk product management
- Better order filtering

## Version 1.2 — Customer Experience
Potential features:
- Customer accounts
- Saved addresses
- Order tracking
- Favorites
- Improved checkout
- Promotional campaigns

## Version 2.0 — Platform Evolution
Potential features:
- Multi-store support
- Multi-location inventory
- Advanced roles
- Audit logs
- Advanced reporting
- Payment integrations
- Shipping integrations

Any feature requiring a new architectural capability must be reviewed against `PRD.md`.
